# Industrial Fault Diagnosis App

An Android application developed for Industrial Instrumentation and Control systems.

## Features

- Fault Diagnosis Module
- SCADA Dashboard Simulation
- Real-Time Parameter Monitoring
- Alarm Management System
- Alarm History Display
- Offline Operation
- User-Friendly Interface

## Technologies Used

- Java
- Kotlin
- Android Studio
- XML
- Git & GitHub

## Modules

### Fault Diagnosis
Allows users to select industrial faults and view possible causes and corrective actions.

### SCADA Dashboard
Displays:
- Tank Level
- Flow Rate
- Temperature
- Motor Status
- Pump Status
- Active Alarms

### Alarm History
Stores and displays previous alarm events.
